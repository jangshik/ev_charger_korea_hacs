# ⚡ Home Assistant - Korea EV Charger

환경부 공공데이터포털 전기차 충전소 API를 연동하여 충전기 상태(충전중, 사용가능 등)를 홈어시스턴트에서 실시간으로 모니터링할 수 있는 통합 구성 요소(Integration)입니다.

## ⚙️ 기능
* **UI 기반 간편 등록:** 지역 코드나 충전소 코드를 찾을 필요 없이 UI 내에서 검색을 통해 충전소를 등록할 수 있습니다.
* **센서 자동 그룹핑:** 전체/급속/완속 사용가능 개수를 요약 센서로 제공하며, 각 포트별 속도(kW), 충전 상태 등을 개별 센서로 분리하여 제공합니다.
* **유연한 폴링(Polling) 설정:** 공공데이터 API 호출 제한 방어를 위해 업데이트 주기를 홈어시스턴트 UI에서 직접 변경할 수 있습니다.

## ⚠️ 공공데이터포털 API 호출 제한 및 폴링 주기 가이드

API 발급 주소
https://www.data.go.kr/data/15076352/openapi.do

공공데이터포털의 API는 계정 유형에 따라 **일일 트래픽(호출 횟수) 한도**가 정해져 있습니다. 한도를 초과하면 당일 자정까지 충전소 상태가 업데이트되지 않으므로, 등록할 충전소 개수에 맞춰 적절한 업데이트 주기를 설정해야 합니다.

### 1. 일반(개발) 계정 기준 : 일일 최대 1,000회 호출 가능
하루는 1,440분이므로 충전소를 1개만 등록할 경우 수학적으로 최소 1.5분(약 1분 30초)마다 호출할 수 있습니다. **(권장 기본값: 3분)**

* **충전소 1곳 등록 시:** `2분` 이상 설정 (일 720회 호출) ➔ **권장 `3분`** (일 480회)
* **충전소 2곳 등록 시:** `3분` 이상 설정 (일 960회 호출) ➔ **권장 `4분`** (일 720회)
* **충전소 3곳 등록 시:** `5분` 이상 설정 (일 864회 호출) ➔ **권장 `5분`**
* **충전소 5곳 이상 등록 시:** `10분` 이상 권장

### 2. 운영 계정 기준 : 일일 최대 100,000회 호출 가능
운영 계정 승인을 받으셨다면 호출 제한에서 거의 자유롭습니다.
* 상태를 즉각 반영하고 싶다면 주기를 **`1분`**으로 화끈하게 설정하셔도 됩니다.
* 1분 주기로 설정해도 1개 충전소 당 하루 1,440회 호출에 불과하므로, 수십 개의 충전소를 모니터링할 수 있습니다.

## 🔧 설정 변경 방법
홈어시스턴트 메뉴의 **설정 ➔ 기기 및 서비스 ➔ Korea EV Charger** 통합 구성 요소 카드에서 **[구성(Configure)]** 버튼을 클릭하여 언제든 분(minute) 단위 주기를 수정할 수 있습니다.
